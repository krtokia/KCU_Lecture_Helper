# 제품형 메뉴 명칭 정리

## 목표

Tampermonkey 메뉴에서 POC·개발·긴 설명 위주의 표현을 제거하고, Helper와 Navigator를
일관된 사용자용 제품 명칭으로 표시한다.

## 현재 상태 확인

- Helper 메뉴는 `KCU Helper:` 접두어와 `현재 켜짐 (클릭하면 꺼짐)` 형태를 사용한다.
- Navigator는 `Beta`, `상태/리포트`, `초기화` 등 개발 검증 중심의 메뉴 명칭을 사용한다.
- 실제 설정 저장 키, 메뉴 handler, 보고서 포맷 및 실행 안전 정책은 검증된 동작이므로
  이번 변경에서 바꾸지 않는다.

## 범위와 비목표

- Helper는 `KCU 학습 도우미`, Navigator는 `KCU 학습 진행` 접두어로 메뉴를 통일한다.
- 토글은 현재 상태와 다음 동작을 짧게 표시한다.
- 메뉴 라벨, 사용자 알림, 주석/사용 안내의 오래된 POC 표현을 현재 Beta 흐름에 맞춘다.
- GM 저장 키, 실행 로직, 보고서의 구조/개인정보 정책, 자동 재개 동작은 변경하지 않는다.

## 수용 기준

- 메뉴만 보고 시작·중지·상태 확인·기록 저장·초기화를 구분할 수 있다.
- Helper 세 토글의 현재 상태와 클릭 뒤 결과가 명확하다.
- 기존 메뉴 handler 수와 설정 저장 동작은 유지된다.

## 검증 계획

1. 두 UserScript 문법 검사, 메뉴 라벨 정적 검사, `git diff --check`.
2. 실제 Tampermonkey 메뉴에서 Helper 4개와 Navigator 6개 항목의 표기를 확인한다.
