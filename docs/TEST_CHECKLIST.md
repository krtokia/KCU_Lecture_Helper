# 검증 체크리스트
아래는 앞으로 수행할 항목이며 통과 기록이 아니다.

## 이관
- [ ] 설치본/로컬 코드의 실제 버전과 헤더 일치, 개인 원본 백업.
- [ ] Helper 하나와 Navigator 하나만 활성화.
- [ ] 로컬 저장 → Tampermonkey 편집기 갱신 → 새로고침 후 새 코드 실행.
- [ ] 브라우저/편집기 재시작 후 연결 상태 확인.
- [ ] 변경된 메타데이터가 실제 설치본에도 반영됨.
- [ ] 배포용 자동 업데이트를 의도치 않게 차단/변경하지 않음.

## 문법
현재 이관된 두 파일에 대해 Node가 준비된 로컬 폴더에서 표준 입력으로 실행한다.

```sh
node --check < src/kcu-lecture-helper.user.js
node --check < src/kcu-auto-navigator.user.js
```

이것은 문법 검사이며 GM API/DOM/iframe/재생/알림 동작을 검증하지 않는다.

## Helper
- [ ] 영상 생성/iframe 교체 후 자동 감지가 올바르게 동작.
- [ ] 자동 2배속 및 기존 배속 복구 정책 유지.
- [ ] 감시 시작 로그와 실제 정지 확정 로그를 구분.
- [ ] 영상 시간이 진행하면 감시 시작만으로 중지 알림이 나가지 않음.
- [ ] 의도적 일시정지 알림 유지.
- [ ] 끝부분 pause/ended 조합의 중복·오판 알림 점검.
- [ ] 브라우저 알림, ntfy 서버 응답, 단말 수신 각각 확인.

## 설정·배포
- [ ] 공개 파일/로그/커밋에 개인 topic/토큰/학번/IP/세션 정보 없음.
- [ ] 신규 설치에서 빈 ntfy 설정은 요청하지 않음.
- [ ] 메뉴에서 유효한 HTTPS 주소를 저장하고 ntfy 사용 여부를 켠 뒤, 새로고침 후 두 값이 유지됨.
- [ ] 메뉴에서 주소를 지우거나 HTTP/잘못된 주소를 입력한 뒤 ntfy 요청이 발생하지 않음.
- [ ] 개인 설정이 업데이트 후에도 유지.
- [ ] LMS/플레이어 iframe에서 설정 일관성 확인.
- [ ] 신규 Raw 설치와 기존 버전 상승 업데이트 각각 확인.
- [ ] 기존 Greasy Fork 설치자의 경로도 확인.
- [ ] 업데이트 확인/자동 설치 옵션 구분.

## Navigator 한 차시 POC
강의실 한 탭에서 진행하고 실제 리포트로 결과를 기록한다.

- [ ] 초기 AJAX 완료 전 잘못된 차시를 선택하지 않음.
- [ ] 열린 주차/영상 있음/출석 미인정 조건 및 현재 과목 ID 일치.
- [ ] 재생 클릭 외 실제 video playing 확인.
- [ ] native ended와 fallback 종료 후보를 구분.
- [ ] 후보 뒤 유예 및 대상 인스턴스/위치 재확인.
- [ ] 실제 새 주차 응답에서 대상 차시 출석 Y 확인.
- [ ] 출석 Y를 영상 100% 시청 증명으로 표시하지 않음.
- [ ] 수동 탐색/새로고침/이탈/iframe 교체/신호 공백 처리 확인.
- [ ] 다음 차시/과목으로 계속 실행하지 않고 한 차시에서 종료.
- [ ] 민감정보 없는 리포트와 미검증 사항 기록.
