# 검증 체크리스트
아래는 앞으로 수행할 항목이며 통과 기록이 아니다.

## 이관
- [ ] 설치본/로컬 코드의 실제 버전과 헤더 일치, 개인 원본 백업.
- [ ] Helper 하나와 Navigator 하나만 활성화.
- [ ] 로컬 저장 → Tampermonkey 편집기 갱신 → 새로고침 후 새 코드 실행.
- [ ] 브라우저/편집기 재시작 후 연결 상태 확인.
- [ ] 변경된 메타데이터가 실제 설치본에도 반영됨.
- [ ] 배포용 자동 업데이트를 의도치 않게 차단/변경하지 않음.

## 문법
현재 이관된 두 파일에 대해 Node가 준비된 로컬 폴더에서 표준 입력으로 실행한다.

```sh
node --check < src/kcu-lecture-helper.user.js
node --check < src/kcu-auto-navigator.user.js
```

이것은 문법 검사이며 GM API/DOM/iframe/재생/알림 동작을 검증하지 않는다.

## Helper
- [ ] 영상 생성/iframe 교체 후 자동 감지가 올바르게 동작.
- [ ] 자동 2배속 및 기존 배속 복구 정책 유지.
- [ ] 메뉴의 자동 배속 ON/OFF가 새로고침 뒤에도 유지되며, OFF일 때 Helper가 playbackRate를 변경하지 않음.
- [ ] 메뉴의 자동 소리 끄기 ON/OFF가 새로고침 뒤에도 유지되며, ON일 때 영상 감지·실제 재생에서만 muted를 적용함.
- [ ] 메뉴의 비의도적 중지 자동 재개 ON/OFF가 새로고침 뒤에도 독립적으로 유지됨.
- [ ] 자동 재개 ON에서 실제 `playing` 뒤 사용자 입력 없이 발생한 pause는 제한 횟수 안에서 재생 재개를 시도함.
- [ ] 자동 재개 OFF에서는 Helper가 `video.play()`를 호출하지 않고 기존 중지 알림만 남김.
- [ ] 플레이어 직접 클릭·키보드 입력 뒤 pause와 그 입력에 이어진 seek 뒤 pause는 자동 재개하지 않음.
- [ ] ended, 종료 직전 pause, seeking 중 pause에서는 자동 재개하지 않음.
- [ ] 재생 거부 또는 반복 pause 시 자동 재개가 무한 반복하지 않고 최대 두 번에서 멈춤.
- [ ] `video.play()`가 resolve된 뒤에도 paused인 사례에서 실제 `playing` 확인 전 최대 두 번까지만 다시 시도함.
- [ ] 자동 재개 진단 리포트가 pause·예약·시도·요청 결과·실제 playing 확인 또는 최대 시도 도달을 시간순으로 남김.
- [ ] 진단 리포트에 URL, ntfy 주소, 키 입력 내용, 세션값이 없는지 확인.
- [ ] Helper 1.1.0에서는 자동 재개 진단 리포트 메뉴가 보이지 않는지 확인. 재노출 시에는
  복사·파일 저장과 `KCU_HELPER_AUTO_RESUME_REPORT` 경계를 다시 확인.
- [ ] 감시 시작 로그와 실제 정지 확정 로그를 구분.
- [ ] 영상 시간이 진행하면 감시 시작만으로 중지 알림이 나가지 않음.
- [ ] 의도적 일시정지 알림 유지.
- [ ] 끝부분 pause/ended 조합의 중복·오판 알림 점검.
- [ ] 브라우저 알림, ntfy 서버 응답, 단말 수신 각각 확인.

## 설정·배포
- [ ] 공개 파일/로그/커밋에 개인 topic/토큰/학번/IP/세션 정보 없음.
- [ ] 신규 설치에서 빈 ntfy 설정은 요청하지 않음.
- [ ] 메뉴에서 유효한 HTTPS 주소를 저장하면 ntfy가 자동 ON이며, 새로고침 후 유지됨.
- [ ] 메뉴에서 주소를 지우면 ntfy가 자동 OFF이고, HTTP/잘못된 주소를 입력한 뒤에도 ntfy 요청이 발생하지 않음.
- [ ] KCU iframe이 있는 강의실에서도 ntfy 설정 메뉴는 한 번만 표시됨.
- [ ] 개인 설정이 업데이트 후에도 유지.
- [ ] LMS/플레이어 iframe에서 설정 일관성 확인.
- [ ] 신규 Raw 설치와 기존 버전 상승 업데이트 각각 확인.
- [ ] 기존 Greasy Fork 설치자의 경로도 확인.
- [ ] 업데이트 확인/자동 설치 옵션 구분.

## Navigator 한 차시 POC
강의실 한 탭에서 진행하고 실제 리포트로 결과를 기록한다.

- [ ] 초기 AJAX 완료 전 잘못된 차시를 선택하지 않음.
- [ ] 열린 주차/영상 있음/출석 미인정 조건 및 현재 과목 ID 일치.
- [ ] 재생 클릭 외 실제 video playing 확인.
- [ ] native ended와 fallback 종료 후보를 구분.
- [ ] 후보 뒤 유예 및 대상 인스턴스/위치 재확인.
- [ ] 실제 새 주차 응답에서 대상 차시 출석 Y 확인.
- [ ] 출석 Y를 영상 100% 시청 증명으로 표시하지 않음.
- [ ] 수동 탐색/새로고침/이탈/iframe 교체/신호 공백 처리 확인.
- [ ] 다음 차시/과목으로 계속 실행하지 않고 한 차시에서 종료.
- [ ] 민감정보 없는 리포트와 미검증 사항 기록.

## Navigator POC 3.2 수동 일시정지

- [ ] 시작 직후 10초 미만의 사이트 자체 pause는 `STARTUP_PAUSE_IGNORED`로만 기록하고 재개 대기로 진입하지 않음.
- [ ] 실제 재생 중 끝부분이 아닌 플레이어 pause에서 `NON_END_PAUSE_OBSERVED`와 `WAIT_MANUAL_RESUME` 확인.
- [ ] pause 뒤 15초 이상 영상이 자동 재생되지 않고, 주차/차시 버튼 클릭이나 출석 재조회가 없는지 확인.
- [ ] 사용자가 플레이어 UI로 재개한 실제 `playing` 뒤 `MANUAL_RESUME_CONFIRMED` 확인.
- [ ] 재개하지 않은 경우 5분 후 안전하게 실패하며 다음 차시를 선택하지 않는지 별도 확인.
- [ ] 재개한 실행은 같은 차시의 native ended 및 새 AJAX 응답 출석 Y까지 기존 절차를 유지하는지 확인.

## Navigator POC 3.3 전체 진단 타임라인

- [ ] 짧은 강의 한 회에서 `timeline`이 시작부터 native ended까지 생성되고 `dropped.timeline`이 0인지 확인.
- [ ] 중간 pause가 없던 실행도 진단 리포트와 기존 native ended/출석 검증까지 정상 완료.
- [ ] 중간 pause 전후 1초 범위에서 media 이벤트, iframe/top focus·visibility, trusted 입력 메타데이터를 시간순으로 비교.
- [ ] 키 문자·키 코드·정확한 좌표·플레이어 URL·원본 RPC가 타임라인에 없는지 확인.
- [ ] `timeupdate`는 최대 초당 한 건으로 제한되며, 전체 타임라인은 5,000건을 초과하지 않는지 확인.

## Navigator POC 3.4 다음 차시 전환 1회

- [ ] 첫 대상의 native ended와 새 주차 응답 출석 Y 확인 전에는 다음 차시 버튼 클릭이 없는지 확인.
- [ ] 다음 대상은 같은 주차의 더 큰 차시 번호부터 뒤 주차 순서로 찾은 첫 출석 N·영상 Y 차시인지 확인.
- [ ] `PASS_NEXT_PLAYING`에 첫 대상/종료 증거/출석 검증/다음 대상/다음 실제 playing이 모두 있는지 확인.
- [ ] 다음 실제 playing 확인 뒤에는 두 번째 종료 대기나 세 번째 차시 버튼 클릭이 없는지 확인.
- [ ] 다음 대상이 없을 때 `PASS_NO_NEXT_ELIGIBLE`로 끝나며 다른 과목·차시 재생이 없는지 확인.
- [ ] 다음 대상 재생 실패, 수동 조작, 신호 공백, iframe 교체는 다른 차시 대체 없이 실패/중단되는지 확인.

## Navigator POC 3.5 첫 과목부터 첫 미수강 과목 탐색

- [ ] 현재 선택 과목과 무관하게 LNB 첫 과목부터 DOM 순서대로 검사.
- [ ] 완료 과목은 적격 차시 버튼 클릭 없이 한 번의 실제 LNB 링크 클릭으로만 다음 과목 이동.
- [ ] 새 페이지에서 10분 이내 handoff의 실행 ID·인덱스·예상 과목 ID를 새 DOM과 대조.
- [ ] 첫 출석 N·영상 Y 과목에서만 첫 적격 차시 버튼 클릭 후 실제 playing 확인, 즉시 종료.
- [ ] 모든 과목 완료 시 `NO_TARGET_ALL_COURSES`; handoff 불일치·이동 실패·수동 조작은 대체 없이 중단.

## Navigator Beta 전체 과목 연속 실행

- [ ] 각 대상의 actual playing, 종료 후보/유예, fresh AJAX 출석 Y 이전에는 다음 버튼 클릭이 없음.
- [ ] 출석 Y 확인 뒤 같은 과목을 다시 조회해 다음 적격 차시 하나만 선택.
- [ ] 현재 과목에 적격 차시가 없을 때만 다음 LNB 과목으로 이동하며, handoff 도착 검증 뒤에만 탐색.
- [ ] 수동 pause는 실제 수동 재개까지 대기하고 `video.play()`·시간·진도·출석 API를 호출하지 않음.
- [ ] 모든 적격 차시 처리 뒤에만 `PASS_ALL_COURSES_COMPLETED`; 모든 완료 기록에 종료 근거와 출석 검증이 있음.
- [ ] 재생/종료/출석/handoff 실패, 사용자 조작, iframe 교체, 신호 공백은 다른 대상 대체 없이 종료.
